Artwork Multi Source Provider

Loads and combines artwork from TVDB and TMDb.

TVDB

Only needed for TVDB accounts/endpoints that require a subscriber PIN. The Jellyfin TVDB project key is built into the plugin.

TMDb

Used for TV and movie image lookups and provider-ID resolution.
Comma-separated ISO 639-1 codes. Use null for images without a language. Leave blank to request all languages.

Ordering

ISO 639-1 language code. Use 00 or null for images without language/text.

Scheduled refresh

Disabled by default. Enable only if the scheduled task should replace manually selected/local artwork as well.
